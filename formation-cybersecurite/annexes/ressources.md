# Ressources

> Une sélection organisée — pas exhaustive, mais **de qualité et fiable**. Privilégiez la
> profondeur à la quantité : mieux vaut finir un excellent parcours que d'en commencer dix.

---

## 🎯 Plateformes de pratique (le cœur de l'apprentissage)

### Généralistes / débutant
- **TryHackMe** — parcours guidés progressifs, idéal pour démarrer (Learning Paths)
- **Hack The Box** & **HTB Academy** — machines réalistes + cursus structurés certifiants
- **OverTheWire** (Bandit, Natas…) — wargames fondamentaux, gratuits
- **picoCTF** — CTF pédagogique (Carnegie Mellon), gratuit
- **Root-Me** — grande variété, FR/EN
- **VulnHub** — machines à héberger dans son lab (hors ligne)

### Web
- **PortSwigger Web Security Academy** — **gratuit, LA référence web** (par les créateurs de Burp)
- **PentesterLab** — parcours web structurés
- **OWASP Juice Shop / DVWA / WebGoat** — applis vulnérables à héberger

### Blue Team / défense
- **CyberDefenders** — investigations DFIR/SOC réalistes
- **Blue Team Labs Online (BTLO)** — scénarios défensifs
- **LetsDefend** — simulateur de SOC
- **Splunk Boss of the SOC (BOTS)** — datasets d'analyse SIEM

### Cloud & spécialisations
- **CloudGoat** (Rhino Security) — AWS vulnérable
- **flAWS / flAWS2** — challenges AWS pédagogiques
- **Kubernetes Goat** — K8s vulnérable
- **pwn.college** — RE & binary exploitation (cursus universitaire gratuit, excellent)
- **crackmes.one** — reverse engineering
- **ROP Emporium**, **exploit.education**, **Nightmare** — exploitation binaire
- **Gandalf (Lakera)** — prompt injection / sécurité IA

### Suivi des compétitions
- **CTFtime.org** — calendrier et classements des CTF

## 📚 Livres essentiels

### Fondations & généralistes
- *Cybersecurity for Dummies* / *Comprendre la cybersécurité* — vulgarisation d'entrée
- **CIS Controls v8** (document gratuit) — à lire en entier
- Guides **ANSSI** (gratuits, en français) — hygiène, durcissement, AD

### Offensif
- *Penetration Testing* — Georgia Weidman (accessible, pratique)
- *The Hacker Playbook 2 & 3* — Peter Kim
- *The Web Application Hacker's Handbook* — Stuttard & Pinto (référence web, un peu datée mais fondamentale)
- *Real-World Bug Hunting* — Peter Yaworski (bug bounty)
- *Black Hat Python* (2ᵉ éd.) & *Violent Python* — scripting offensif
- *RTFM (Red Team Field Manual)* — aide-mémoire

### Défensif / DFIR / malware
- *Blue Team Handbook* — Don Murdoch
- *The Practice of Network Security Monitoring* — Richard Bejtlich
- *Practical Malware Analysis* — Sikorski & Honig (référence RE/malware)
- *Practical Forensic Imaging* / *The Art of Memory Forensics*
- *BTFM (Blue Team Field Manual)*

### Fondamentaux techniques
- *TCP/IP Illustrated* — Stevens (réseau en profondeur)
- *Serious Cryptography* — Aumasson (crypto moderne, accessible)
- *The Art of Software Security Assessment* — revue de code sécurité
- *Practical Binary Analysis* — reverse/exploit

### Culture & carrière
- *Sandworm* / *This Is How They Tell Me the World Ends* / *Countdown to Zero Day* — journalisme cyber
- *Tribe of Hackers* — parcours et conseils de professionnels

## 🛠️ Outils par catégorie (déjà installés dans Kali pour la plupart)

- **Reconnaissance** : nmap, masscan, subfinder, amass, theHarvester, Shodan, recon-ng, SpiderFoot
- **Web** : Burp Suite, OWASP ZAP, ffuf, gobuster, sqlmap, nikto, wpscan, nuclei, whatweb
- **Exploitation** : Metasploit, searchsploit, msfvenom
- **Mots de passe** : hashcat, john, hydra, crackmapexec/netexec
- **AD** : BloodHound, Impacket, PowerView, Mimikatz, Certipy, Responder, evil-winrm
- **Réseau** : Wireshark, tcpdump, Scapy, bettercap, tshark, Zeek
- **Pivoting** : chisel, ligolo-ng, sshuttle, proxychains
- **Blue/SIEM** : Wazuh, Elastic (ELK), Splunk, Sysmon, Sigma, YARA
- **Forensics** : Volatility, Autopsy/TSK, Eric Zimmerman's Tools, KAPE, Plaso
- **Malware/RE** : Ghidra, IDA, radare2/Cutter, x64dbg, REMnux, FlareVM, Any.Run
- **Cloud/DevSecOps** : Prowler, ScoutSuite, Pacu, Trivy, Grype, Checkov, tfsec, gitleaks, kube-bench, kube-hunter
- **Labs** : GOAD, DetectionLab, Kubernetes Goat, CloudGoat, Vagrant, Proxmox
